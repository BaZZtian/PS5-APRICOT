# Controller prompt artwork

Based on "Playstation 5 Dualsense" by AHarmlessPotato.
Source: https://sketchfab.com/3d-models/playstation-5-dualsense-878c1f882808477ab81c2fe86d5a3936
Author: https://sketchfab.com/AHarmlessPotato
License: CC BY 4.0 - https://creativecommons.org/licenses/by/4.0/

Reused the retained PhazonPrime rendered components. The supplied model metadata
identifies this author and license; this import does not assert fresh online verification.
Modifications: disconnected component extraction, orthographic rendering with original
base-color textures and authored lighting, shoulder relabeling, L/R and L3/R3 labels,
40-pixel prefiltering and RGBA compositing. Options and touchpad graphics were authored
for ApricotGS. No game imagery, texture or font was extracted for these prompts.
The generated controller_art.hpp contains the same CC BY 4.0 artwork; its inclusion
does not relicense it under the surrounding runtime source license.
